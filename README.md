# EcoTech Evolution Website

Website for EcoTech Evolution, a renewable energy solutions company in Struga.

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev --hostname 127.0.0.1 --port 3000
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000) in your browser.

## Scripts

```bash
pnpm dev
pnpm build
pnpm start
```
