# 12\. Content Rules So the Website Does Not Sound Cringe

- Use real product categories and real installation photos wherever possible.
- Use local wording: Struga, Ohrid region, homes, businesses, installation, offer, consultation.
- Show product details: brand, model, capacity, energy class, system size, room/building type.
- Avoid abstract eco slogans unless paired with practical benefit: lower bills, comfort, support, warranty.
- Never claim official partnerships, certifications, 24/7 support, or guaranteed savings unless verified.
- Prefer Albanian and Macedonian content for trust, with English as optional secondary language.
